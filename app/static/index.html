What the service provides

A focused API with visible methods.

The first public demonstration turns a USGS elevation workflow into an approachable web map. Draw one point or one line, submit it to the Logic Cloud Geo elevation API, and review the returned coordinates, elevations, and profile results.

The same service also supports Python, Jupyter, ArcGIS Pro, and other clients that can send standard HTTPS requests.
