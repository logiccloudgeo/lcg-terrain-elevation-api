How it works

The USGS 3D Elevation Program publishes digital elevation models of the bare ground. The LCG service uses Py3DEP to sample USGS terrain at a nominal 1/3 arc-second spacing, about 10 meters.

Submit WGS 84 latitude and longitude. The API validates the coordinates, retrieves elevations, and returns meters or international feet with dataset and reference metadata. For a profile, sample coordinates along a line, query them as a batch, and plot elevation against distance.

Service contract

One point or an ordered batch.

The single-point endpoint is useful for map clicks and simple lookups. The batch endpoint accepts as many as 500 uniquely keyed coordinates and returns them in request order, making it suitable for GIS joins and profile workflows.

Set units to feet or meters in either request to choose the elevation units.

GET /api/v1/elevation

Latitude, longitude, and requested units.

GET /api/v1/elevation?latitude=30.4383&longitude=-84.2807&units=feet
Run point example
POST /api/v1/elevations

An ordered list of keyed points, with a 500-point request maximum.

{
  "units": "feet",
  "points": [
    {"db_key": "A", "latitude": 30.4383, "longitude": -84.2807},
    {"db_key": "B", "latitude": 30.4420, "longitude": -84.2850}

Appropriate use

        

          Returned values are samples from a digital elevation model. They are useful for mapping,
          screening, visualization, profiles, and reproducible analysis, but they are not surveyed
          spot elevations and should not replace project-specific engineering or legal surveys.
